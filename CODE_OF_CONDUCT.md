# Code of Conduct

## Our Standard

Participation should be respectful, patient, technically honest, and welcoming.
Constructive review focuses on evidence and the work, not the person. Safety
concerns are raised clearly and treated seriously.

Acceptable behavior includes:

- giving actionable feedback with enough context to reproduce it;
- acknowledging uncertainty and correcting mistakes;
- respecting different experience levels and backgrounds;
- protecting private information and responsibly reporting vulnerabilities;
- stopping a discussion that encourages unsafe hardware operation.

Harassment, threats, discriminatory language, personal attacks, deliberate
misinformation, credential disclosure, and pressure to bypass safety controls
are not acceptable.

## Enforcement

Report conduct concerns privately through the repository maintainer's GitHub
profile. Maintainers may edit or remove contributions, lock discussions, issue
warnings, or temporarily/permanently restrict participation. Reports will be
handled as privately as practical.

This code applies in repository spaces and when representing the project in
public spaces.
