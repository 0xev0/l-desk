# Support

Use the repository issue forms for reproducible firmware bugs, hardware
compatibility reports, and feature proposals.

Before asking for help:

1. Remove motor power if behavior is unexpected.
2. Read [`docs/troubleshooting.md`](docs/troubleshooting.md).
3. Confirm the exact board, actuator, Hall output, BTS7960 module, pinout, power
   supply, and firmware commit.
4. Run the host tests and include the failing test output.
5. Remove credentials, private keys, MAC addresses, and private network details
   from logs.

General installation questions may use GitHub Discussions once enabled.
Security vulnerabilities must follow [SECURITY.md](SECURITY.md), never a public
issue.

This community project provides no warranty, emergency response, certification,
or guarantee that a specific mechanical/electrical design is safe.
